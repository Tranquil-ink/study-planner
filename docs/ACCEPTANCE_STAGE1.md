## 手机 → 电脑 → 手机

1. 手机与电脑打开同一 HTTPS 网址，使用同一个 A 账号登录。首次成功读取为空；未获取成功时应提示错误，不能冒充空库。
2. 手机进入任务池，创建“物理”分类，创建“理论力学”：单位“节”、总量 40、初始已完成 8、位置 `2.1.1`。等待“已保存到云端”。电脑点击“获取最新数据”，应见相同任务、8/40 和位置文字。
3. 电脑编辑名称、备注和颜色并保存；手机主动获取最新数据后应一致。修改总量为 7 应被拒绝，原任务仍为 8/40。留空总量应允许保存。测试 0.5 单位；不应生成学习时间或速度。
4. 电脑归档任务，手机刷新后在“显示已归档分类与任务”看到；取消归档同样双向可见。归档分类不删除任务；不可硬删除引用中的分类。
5. 仅清除手机测试网站的数据，重新打开并登录 A，所有已确认数据仍可取回；未提交草稿会丢失是预期。不要清理其他应用或正式账号数据。

## 网络、版本与幂等

6. 两台设备先获取相同版本并打开同一任务表单。手机保存修改；电脑保存旧表单，必须报版本冲突且保留输入。电脑“获取最新数据”后表单不能自动变为可保存；核对最新列表后点击“已核对，将此输入应用到最新版本”，再保存，手机刷新验证。
7. 电脑打开表单但先不保存。手机从文件预检并恢复一次。电脑旧表单保存必须冲突；另一设备刷新应见恢复的数据。
8. 浏览器开发者工具断网后获取，提示取数失败，已有列表保留并注明可能过期，最近成功获取时间不前移；第一次就断网不能显示空库。恢复网络后手动获取成功。
9. 填写任务后断网再保存，不得显示成功；当前输入保留，显示结果待确认（传输层无法证明请求从未到达）。联网后点击“确认并重试原请求”，只能创建一项。重复快速点击保存也只应一次。
10. 执行 `npm run test:integration` 验证真实事务已提交但响应丢失：查回执、原 ID 重试只提交一次，同 ID 换内容拒绝。脚本同时覆盖多表替换中途外键失败回滚和真实并发竞争。保留命令退出码及结果。
11. 在测试环境阻断 token 刷新并等访问 token 失效（不要改正式项目设置），再提交。应要求登录、停止业务操作，不展示个人数据或伪成功；同账号重登后核对保留输入/原请求。显式退出会清除草稿和缓存，后退不得显示个人数据。自然过期与主动退出分别记录。

## 权限、备份与本地迁移

12. 运行真实集成脚本验证全部表与 RPC 的匿名/跨账号/伪造 owner/绕过直写访问。仅观察登录页面不能代替权限检查。确认公开注册和匿名登录在项目设置中关闭。
13. 手机数据设置导出 JSON，确认系统下载目录有文件；文件含全部分类、任务（含归档）和设置，没有密码/token/key。页面只能确认生成文件，不能证明系统已保存。
14. 修改测试数据，再选择原文件。核对来源版本、文件数量及云端数量；不勾选“替换当前账号全部业务数据与设置”不得恢复。确认恢复，电脑刷新比对 ID、名称、分类、数值、位置、备注、归档与设置一致。服务器审计时间会重建，不应照抄旧时间。
15. 导入损坏 JSON、未来版本、重复 ID、悬空分类、负数、超总量、未知字段；都应失败，重新获取确认旧数据未损坏。预检后另一设备先写入，恢复须冲突并要求重新选择文件预检。
16. 按 DATA_MODEL.md 的约定 v0 虚构样例预检，应显示 v0 → v1；确认后另一设备可见且 ID/位置不变。未知 IndexedDB 格式应拒绝，不声称已迁移真实数据。若有真实旧数据，先在原浏览器原网址导出、提供格式，再补适配验收。
