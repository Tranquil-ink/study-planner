- [ ] 两端同时打开同一实际记录，先保存者成功，后保存者冲突并保留输入。获取最新后不自动采用新版本，须核对并显式重新应用。若记录已被删除／恢复移除，不能用旧编辑器复活它。
- [ ] 两端分别新增“单条未超量、合计会超量”的进度；同一基础版本仅一方成功，失败方刷新核对后仍超总量则被拒绝。
- [ ] 提交前断网不显示成功，表单保留。模拟提交成功但响应丢失后，“确认并重试原请求”不再增加记录、进度、创建顺序或版本；删除重试也不误删其他记录。自动脚本能模拟响应丢失，实机不能方便模拟时如实记录未验证。
- [ ] 断网读取不冒充空库；会话失效重登前不展示未授权内容。同账号重登后可确认原请求。关闭页面会丢失内存草稿／待确认请求，需重新取数核对，不能盲目新建。
