# 阶段 5 验收

通过新版 HTTPS 前端登录已升级的 Supabase 隔离测试项目。在安卓手机和电脑分别操作。记录部署提交、迁移执行情况、设备、日期与逐项结果。

| 场景 | 预期 |
| --- | --- |
| 任务池录入 | 未安排的临时课程报告留在收件箱。教材与习题集可以归到同一项目，预计时长、重要程度、截止日期可见。 |
| 容量与计划 | 模板填 180 分钟，计划累计 240 分钟。显示超出 60 分钟。本周例外不回写模板。确认周初目标后可新增任务。 |
| 同日多项 | 将教材拆为两次分配，且同一天再分配一个报告。日视图显示不同计划时长，不要求选择起止钟点。 |
| 计划和实际 | 计划 120 分钟，记录实际 80 分钟与 6 页。另有未来安排 20 页，目标 30 页时仍需安排 4 页。已经过去或设为已处理的安排不继续覆盖未来目标。 |
| 实际日期 | 改期或删除原安排，实际发生日期和学习量仍与原记录一致。无计划也可补记。 |
| 退回与结转 | 未完成事项可以退回或结转。结转不会更改原周基线，下周可重新估时和设目标。勾选一次性待办完成不生成实际投入。 |
| 复盘 | 周初计划读 30 页，改为 6 页且实际读 6 页，分别显示 20% 和 100%。临时新增单列，近 4／12 周可切换。 |
| 双设备 | 手机保存后，电脑点击账号中的获取最新数据可读到。两个设备同时编辑，以旧版本保存被拒且保留输入。 |
| 备份与权限 | 验证 v5 完整导出、失败恢复不更改账号、成功恢复后另一设备读取。使用两个空账号运行真实项目集成脚本。 |

测试项目数据全为虚构样例。阶段 4 可通过 Git 提交 `94a970a` 查看。每项结果以真实执行记录为准。
