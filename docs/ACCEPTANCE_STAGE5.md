# 阶段 5 验收

## 日程与任务池界面

| 场景 | 预期 |
| --- | --- |
| 日期列 | 调整桌面窗口宽度，日期列随可用空间变化。屏幕放不下整周时，可以用看板上方的箭头翻到同一周的其他日期。 |
| 周目标 | 点日程工具栏的「周目标」查看所选周的预算和进度。桌面侧栏可以和看板同时使用，窄屏抽屉可以用关闭按钮或 Esc 退出。 |
| 卡片菜单 | 鼠标移到安排上或用键盘聚焦时可找到「⋯」。手机直接显示菜单入口。可以用菜单移动安排或标记未做，完成勾选始终可见。 |
| 新增与容量 | 在任务池分类或项目旁点「＋」挑选任务类型。在本周目标页用「容量设置」管理默认容量和本周例外。 |

## v0.5.2 周期任务和周目标

| 场景 | 预期 |
| --- | --- |
| 预期目标 | 长期任务周初到 250 页，在设定目标时填 300。表单预计新增 50 页。周中记到 275 页后，再打开输入仍显示 300。 |
| 新增入口 | 「新增分类」位于任务池筛选区上方。「新增周期任务」和「新增长期任务」可从分类或项目的「＋」菜单选择。 |
| 周期任务 | 设置每周 45 分钟并激活，本周目标马上显示计划时长和未完成。通过日程勾选完成，本周显示已完成。切到下周，仍有 45 分钟的目标，状态为未完成。 |
| 剩余时间 | 本周可用 4 小时，排 1.5 小时，显示剩余 2.5 小时。用不同的实际时长完成安排，剩余量保持 2.5 小时。 |
| 升级与恢复 | 在已经执行日程看板迁移的库应用新迁移。验证原 v5、v6 备份预检，以及 v7 周期任务、预测周次和各周完成日期恢复。 |

## v0.5.1 日程看板

登录已升级的 Supabase 隔离测试项目，在安卓手机和电脑上分别验证。

| 场景 | 预期 |
| --- | --- |
| 任务池 | 在分类和项目内新增任务。在收件箱新增临时待办并填写截止日。激活长期任务后，切周或在另一设备取数仍显示激活。 |
| 本周目标 | 临近截止的待办自动出现。设定计划 `4 h` 和新增 `50 页` 后，按钮变为「编辑目标」。确认周初计划后保留原值。 |
| 容量 | 分别填上午 `1.5 h`、下午 `0.5 h`、晚上 `0.5 h`。选择本周临时配置后，默认配置继续保留。 |
| 日程移动 | 在同一时段创建两条，再拖动重排。拖到另一日或用手机移动表单改到晚上。日程顺序在另一设备取数后相同。 |
| 完成 | 对计划 `1.5 h` 的长期任务点 ✓，弹窗默认 `1.5 h`。填实际 `1.25 h` 和读到 275 页。若周初 250 页、目标 300 页，则周进度显示 `p275 / p300 · 50%`，对应预算只扣计划时间。 |
| 未做 | 临时待办点 × 后保留已排分钟，已完成比例不增加，待办仍可在任务池找到。 |
| 每日进度 | 2.5 小时容量安排 3 小时，显示 120% 且条形全满。5 条安排完成 2 条，应显示 40%，未做仍计入分母。 |
| 复盘 | 两种分类记录实际，切换近 4／12 周，检查堆叠趋势、饼图和各长期任务的平均完成率。 |
| 备份和升级 | 记下旧日程、日容量与实际记录，应用新迁移后核对。把 v5 导出文件预检并恢复到隔离账号，再回读 v6 的时段、状态和实际顺序。 |
| 双设备 | 保存后在另一端获取最新数据。旧表单使用过期版本提交时保留输入，响应丢失后可确认原请求。 |

真实项目配置及执行命令见 [Supabase 配置](SUPABASE.md)。v0.5.0 的历史验收清单可在合并提交 `6e8c87e` 中查看。
