## 补充业务与失败路径

- [ ] 投入型目标只需目标分钟，可填进度参照；进度型需正数精确目标；一次性事项加入周前必须补估时。
- [ ] 截止日期无效、0/负数/小数分钟、进度超精度、同周重复均不能保存；不同单位不相加。
- [ ] 日历可用底色与容量相符；可用外安排仍允许，显示额外安排且不扩容量。已排／实际各按原数据汇总，排程或确认计划不产生实际。
- [ ] 勾选下周带入，在下一周点击载入草稿。目标待核对，新的条目ID、原任务ID、无确认时间、无自动日程；已存在同任务不重复添加。未勾选／已取消不带入。
- [ ] 两端同时编辑同周，先保存成功，后者冲突且输入保留；获取最新不自动采用新版本，明确核对后再保存。
- [ ] 保存前断网：不显示成功；恢复网络后确认并重试原请求，不能重复新增待办／历史。
- [ ] 模拟已提交响应丢失：确认回执、同requestId重试，版本和历史只增加一次；实机不能方便模拟时如实记录未验证。
- [ ] 表单切页、主动取数、会话失效同账号重登保持输入；退出/刷新前提示，不伪造本地云端成功。
- [ ] 已有周计划引用的任务单位不能修改；改任务名称不生成新任务，历史保留当时标题。
- [ ] 归档待办仍可查看历史执行周；修改待办估时不追溯改写已保存周目标。
