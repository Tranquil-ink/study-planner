# 学习日程规划器功能设计说明 · v0.5.2

**版本基线**　`main` 合并提交 `875a0f4`，2026 年 11 月 27 日。[PR #10](https://github.com/Tranquil-ink/study-planner/pull/10)

用任务池整理要做的事，用本周目标决定这周做到哪里，再把时间排到具体日期。每天做完后记实际，复盘时可以看清原计划、当前目标和实际投入。

**任务池 → 本周目标 → 日程 → 今天／实际记录 → 复盘**

日期按北京时间计算，一周从周一到周日。手机和电脑使用同一个账号，云端保存任务、计划和实际记录。

## 1. 页面入口

| 页面 | 用途 |
| --- | --- |
| 今天 | 看今天早中晚的安排和实际记录，补记学习，处理过去未收尾的安排。 |
| 任务池 | 建分类、项目和任务，设置激活状态，查看长期任务累计进度。 |
| 本周目标 | 选择任务，设置预期进度、计划时长和可用时间，查看两种剩余时间。 |
| 日程 | 在周视图或日视图添加、移动、完成安排，查看所选周的任务预算和进度。 |
| 复盘 | 对照周初计划、当前目标和实际投入，查看近 4／12 周的图表。 |
| 数据设置 | 导出和恢复学习数据。账号菜单可获取最新数据或退出登录。 |

## 2. 任务池

「新增分类」在顶部。分类可设颜色，也可建项目，把同一课程或主题下的任务放在一起。分类和项目内各有新增入口。未分类的临时待办放在收件箱。列表支持按类型筛选、搜索，以及查看完成和归档的事项。

| 类型 | 建立时填写 | 进入本周目标 | 如何判断完成 |
| --- | --- | --- | --- |
| 长期任务 | 分类、名称、进度单位。可设项目、总量、初始累计量、初始章节位置、优先级和截止日。 | 激活后出现在候选清单，点「设定目标」纳入当周计划。也可以在本周页面主动选择。 | 按当周进度目标判断。只设时长时，按实际投入判断目标是否达到。 |
| 周期任务 | 分类、名称和每周时长。可设项目、优先级及备注。 | 激活后按预设时长自动进入每周计划。 | 每周只有「已完成」和「未完成」。在日程勾选完成后，按实际学习日期记入对应周。 |
| 临时待办 | 名称。可设分类、项目、预计时长、优先级和截止日。 | 激活后成为候选。未完成且截止日早于所选周周一加 14 天时也会出现，包含已逾期的待办。 | 在日程勾选完成后记录完成日期。未完成的待办继续留在任务池。 |
| 独立任务 | 在日程内填写名称和计划时长。 | 直接排到日期和时段。 | 记录该张日程卡片的完成和实际时长。 |

- **激活状态跨周保存。** 实心开关表示已激活。取消激活会停止自动纳入新周，已保存的周目标可在对应周查看或管理。归档的任务及挂在归档分类、项目下的任务会退出新增计划的候选清单。
- **累计进度以实际记录为准。** 任务池显示初始累计量加上已记录的进度增量。设了总量时，进度条按「当前累计量 ÷ 总量」计算。章、节等位置文字和可加减的进度数值各自保存。
- **周期任务每周重新计状态。** 首次激活会生成当周目标。再次打开时会补齐激活且可规划期间已经到来的周。未来周可提前看到预设目标，已经保存的周目标保留自己的时长。一次完成只计入实际发生的那一周。

## 3. 本周目标和时间容量

### 设定目标

每项任务每周最多有一条目标。可以从候选清单点「设定目标」，也可以点「选择本周任务」加入其他事项。保存后入口变为「编辑目标」。周期任务自动带入每周时长，也可编辑所选周的时长。

长期任务填写**预期目标页码**，或按任务单位填写预期到达量。系统用预期值减去周初累计量，得到本周计划新增量。周初累计量取初始量加上周一以前的实际增量。预期位置应高于周初位置，留空即可只设时长。

每条目标显示本周计划时长、剩余预算和周进度。长期任务的进度条按本周实际新增量计算，周期任务和临时待办显示完成状态。排到具体日期以及勾选完成，都在「日程」操作。

「确认周初计划」保存确认时的目标和时长，供复盘对照。确认后仍可调整当前目标。中途加入的事项会在复盘中计为周中新增，取消的目标可从「历史调整」查看。

### 设定容量

- 「编辑默认配置」设置平时一周的可用时间。周一到周日各填上午、下午、晚上，可输入 `0.5`、`2.5` 小时，也可以填 0。
- 「采用默认配置」用当前模板设置所选周。「本周临时配置」只改所选周，表单里的「载入默认值」可以先把模板填进去。每天三个时段合计最多 24 小时。
- 页面顶部显示「每周可用」「目标计划」和「剩余可安排时间」。目标计划超过容量时会提示，仍可继续安排。容量未设时，剩余可安排时间显示「未设置」。

## 4. 日程和今天

### 看板和移动

「日程」顶部是所选周的任务摘要，可看到已设目标的剩余预算和进度，也能看出哪些任务待设目标。下方按日期排成列，每天用浅横线分成上午、下午、晚上。电脑默认打开周视图，窄屏默认打开日视图，两种视图都可手动切换。可以跳转日期，也可以点周视图中的星期进入该天。

每个时段都有「新增安排」。可以选已有的长期任务、周期任务或临时待办，也可以新建后直接关联，或者建独立任务。输入计划时长，例如 `2` 或 `2.5` 小时。长期任务还可填该次计划新增量和目标位置。卡片会显示任务名、计划时长、分类和已经记录的实际时长。

电脑可以跨天、跨时段拖动，也可以在同一时段内重新排序。手机或键盘操作可用「移动」，选择日期、时段和放置位置。点击卡片标题可编辑或删除安排。实际投入一直按发生日汇总，删除安排或改换关联任务时，原实际记录转为无安排关联的记录。

### 完成、未做和补记

| 操作 | 保存结果 |
| --- | --- |
| 点 ✓ 后「保存并完成」 | 弹窗默认填计划时长，可修改实际时长和实际学习日期。长期任务可填实际到达页码或数量，以及章、节位置。保存会写入实际记录并点亮完成标记，临时待办和周期任务的完成状态也随之更新。已有实际的安排可沿用最近一条记录。 |
| 未记录实际时点 × 标记未做 | 卡片显示「未做」。计划时长继续计入预算和当日已安排时长，实际投入仍按已有学习记录计算。未做的卡片可以撤销，回到待完成状态。 |
| 在「今天」或日视图补记实际 | 可以为长期任务、周期任务、临时待办或独立事项补录实际。已有实际记录可以编辑或删除。需要确认安排或待办完成时，使用日程卡片上的 ✓。 |

「今天」还会把过去尚待处理的安排收在一个列表里，可以从这里完成、标记未做或移动。

## 5. 指标怎么算

| 指标 | 计算 |
| --- | --- |
| 任务池累计进度 | 当前累计量 ÷ 任务总量。当前累计量来自初始量与实际增量。 |
| 本周目标新增量 | 预期目标位置 − 周初累计位置。 |
| 本周进度 | 本周实际新增量 ÷ 本周计划新增量。旁边的页码显示累计位置和目标位置，例如 `p275 / p300`。 |
| 单个任务剩余预算 | 该任务本周计划时长 − 该任务在这周全部安排的计划时长。超出时显示超出预算的时长。 |
| 整周剩余可安排时间 | 全周七天的可用时间 − 本周全部安排的计划时长，最低显示 0。 |
| 每日已安排比例 | 当日已安排的计划时长 ÷ 当日可用时间。超出 100% 时保留实际百分比，进度条填满。当天容量为 0 而有安排时，提示「超额 · 无可用时间」。 |
| 每日完成比例 | 当日标记「已完成」的卡片数 ÷ 当日全部安排数。「未做」计入总数。空白日显示 0%。 |

**例子**　量子力学周初读到 250 页，目标填 300 页，系统算出计划新增 50 页。实际读到 275 页时，本周新增 25 页，显示 `p275 / p300 · 50%`。如果任务总量是 500 页，任务池显示累计 `275 / 500 页`，条形比例为 55%。

假设该任务本周计划 4 小时，分两张卡安排 2.5 小时和 0.5 小时。第一张实际做了 2 小时，第二张标记未做。该任务仍按已排 3 小时算，剩余预算 1 小时。如果全周可用 10 小时且只有这两张卡，整周剩余可安排时间是 7 小时。两张卡若在同一天且当天容量为 2.5 小时，当天已安排为 120%，完成比例为 50%。

## 6. 复盘

- **周目标对照。** 并排看周初计划、当前计划和实际投入，显示目标达成情况。实际日期所在周决定这笔学习计到哪一周。计划外投入指该周未归入当前有效周目标的实际时长。
- **投入趋势。** 切换近 4 周或近 12 周，比较各周计划时长和实际时长。实际投入按分类颜色堆叠，独立任务或无分类记录归为「未分类」。
- **学习分布。** 饼图显示所选范围内，各分类实际投入占总实际投入的比例。
- **长期任务平均完成率。** 对同一长期任务，在所选范围内取已设数值进度目标的各周完成率平均。累计进度另列。周期任务的周目标继续用已完成／未完成表示。

周末未做完的长期任务，累计量从已记录的实际继续往后走，下周可另设预期位置。未完成的临时待办仍在任务池，符合截止日或激活规则时会再次出现在候选清单。

## 7. 账号、保存和备份

- **账号与同步。** 使用 Supabase 邮箱和密码登录。账号数据隔离。另一台设备可在账号菜单点「获取最新数据」，页面同时显示最近一次成功读取的时间。
- **保存与冲突。** 修改提交到云端后才显示保存成功。若另一台设备已更新，表单会保留输入，核对后可用最新版本继续保存。若网络中断、无法确定保存结果，可用「确认并重试原请求」找回回执，重复确认同一请求只应用一次。
- **完整备份。** 导出 v7 JSON，包含任务、分类与项目、激活状态、周目标和容量、周期任务各周完成状态、日程和实际记录。可导入 v5、v6 和 v7。选择文件后先校验并显示数量预览，确认才替换当前账号的业务数据与设置，失败会整体回滚。
- **升级。** 从 v0.5.1 升级时，先导出备份，再应用 `202611270001_weekly_recurring_tasks.sql`，随后部署 v0.5.2。已有临时待办、实际记录和周目标可继续使用。 [Supabase 升级说明](https://github.com/Tranquil-ink/study-planner/blob/875a0f40d408d6f3b4474829d0aa469ae774429a/docs/SUPABASE.md)

## 8. 界面方向与验证

当前界面以日期列、时段加号和卡片就地完成为主。修改计划最后提出的界面方向是压缩页面留白和卡片间距、减少装饰，参考 Sunsama 截图中信息和操作的摆放。这项视觉重设计属于后续需求。
